# Module 1 Labs

- **`lab_1_1_chatbot_solution.py`** — Lab 1.1: chatbot with and without
  conversation memory. See [Capstone Checkpoint 1.1](../../Capstone%20Checkpoint%201.1),
  which builds on this same pattern.
- **`lab_1_2_keyword_retrieval_starter.py`** — Lab 1.2: BM25 keyword retrieval
  over a company email corpus. Starter has two TODOs: `tokenize()` and
  `Bm25Retriever.getTopK()`/`retrievedContext()`.
- **`detailedEmails/`** — course-provided email dataset the Lab 1.2 script
  indexes (one `.txt` per email). Not committed to this repo (large,
  course-provided — see `.gitignore`); place it here locally to run the lab.
